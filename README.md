# Daiyndal — магазин пробных тестов и материалов

РФМШ · НИШ (НЗМ) · БИЛ · IELTS · TOEFL. Статический сайт + Vercel Functions, без зависимостей и сборки.

## Страницы

| Путь | Что это |
|---|---|
| `/` | Лендинг и каталог с ценами (каз/рус) |
| `/rfmsh/` | Прежний сайт РФМШ: лендинг и 15 вариантов (старая ссылка `/#practice` ведёт сюда) |
| `/test.html?cat=nzm\|bil\|ielts\|toefl&id=…` | Прохождение теста; `&demo=1` — бесплатное демо |
| `/my.html` | «Мои тесты»: всё купленное, коды активации |
| `/material.html?id=formulas\|nisguide` | Платные материалы (отрывок бесплатно) |
| `/english.html` | Бесплатный гид по IELTS и TOEFL |
| `/admin.html` | Выпуск кодов для ручных продаж, восстановление кода по платежу |
| `/oferta.html`, `/privacy.html` | **Шаблоны** — заполнить реквизиты и проверить у юриста |

## Как устроен доступ

- Регистрации нет. После оплаты или ввода кода сервер выдаёт подписанный токен (HMAC, `SHOP_SECRET`), он хранится в браузере.
- Код активации (`XXXX-XXXX-XXXX-XXXX`) подписан тем же секретом и открывает товар на любом устройстве. Старые коды РФМШ продолжают работать.
- Задания РФМШ, правильные ответы и проверка теперь только на сервере (`api/rfmsh.js`), а раньше лежали открыто в `index.html`.
- Пробники НИШ/БИЛ/IELTS/TOEFL читаются из базы Beles (Supabase): `bt_exams` с `practice = true` и опубликованные `ielts_tests`. Ответы клиенту не отправляются, проверка на сервере.

## Настройка в Vercel

Project → Settings → Environment Variables — см. `.env.example`. Минимум: `SHOP_SECRET`, `ADMIN_PASSWORD`. Для карты: `CP_PUBLIC_ID`, `CP_API_SECRET` (CloudPayments). Для НИШ/БИЛ/IELTS/TOEFL: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`.

Без ключей CloudPayments кнопка оплаты ведёт в WhatsApp, как раньше.

## Цены и товары

`api/_lib/catalog.js`. Новые товары добавляйте **только в конец списка**, не удаляйте и не переставляйте — номер товара зашит в коды. Чтобы снять товар с продажи: `hidden: true`.

## Локально

```
SHOP_SECRET=dev node scripts/dev.js   # http://localhost:3000
npm test                               # тесты API (без сети)
```
